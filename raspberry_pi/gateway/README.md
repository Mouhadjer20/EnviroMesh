# EnviroMesh Gateway (RPi 1)

The Gateway Raspberry Pi (RPi 1) is the first reception and edge processing layer in the EnviroMesh network architecture.

Every telemetry message generated by ESP32 sensor nodes (LoRa or Wi-Fi) passes through RPi 1 first before forwarding to the central Core processing server (RPi 2).

## Responsibilities

1. **LoRa 433 MHz Reception**: Direct reception from SX1278 RA-02 via hardware SPI (`/dev/spidev0.0`).
2. **Wi-Fi MQTT Ingestion**: Local EMQX broker receiving MQTT telemetry on `enviromesh/devices/+/telemetry`.
3. **Payload Normalization & Validation**: Validation of ranges and types, normalization into a standard envelope.
4. **Metadata Attachment**: Enriches packets with `message_id` (stable UUID), `gateway_id`, `gateway_received_at`, and signal metrics (`rssi_dbm`, `snr_db`).
5. **Persistent Offline Queue**: Stores messages in SQLite with WAL mode (`PRAGMA synchronous = FULL`) to guarantee zero data loss if RPi 2 or the local network goes down.
6. **Reliable MQTT Forwarding**: Dequeues and forwards messages over TLS (port 8883) to RPi 2's EMQX broker with MQTT QoS 1. Messages are only deleted from the queue upon receiving `PUBACK`.

## Directory Structure

```
raspberry_pi/gateway/
├── docker-compose.yml       # Orchestrates local EMQX and Python gateway service
├── Dockerfile               # Gateway container build recipe
├── requirements.txt         # Python dependencies
├── .env.example             # Gateway environment template
├── emqx/
│   ├── emqx.conf            # Local EMQX configuration
│   └── acl.conf             # Strict per-device ACLs
├── certs/                   # CA certificates for TLS to RPi 2 (gitignored)
│   └── core-ca.crt
├── data/                    # SQLite queue persistence (gitignored)
└── gateway/
    ├── __init__.py
    ├── config.py            # Environment configuration
    ├── logger.py            # Structured logging
    ├── sqlite_queue.py      # SQLite WAL persistent queue
    ├── telemetry_validator.py # Range and structure checks
    ├── telemetry_normalizer.py# Uniform envelope generator
    ├── lora_receiver.py     # SX1278 SPI driver and receiver loop
    ├── mqtt_ingestion.py    # Local MQTT subscriber
    ├── mqtt_forwarder.py    # TLS MQTT publisher to RPi 2
    ├── health_monitor.py    # Queue depth and health logging
    └── main.py              # Application lifecycle entrypoint
```

## Quick Start

1. **Hardware Setup**:
   Ensure SPI is enabled in `raspi-config`:
   ```bash
   sudo raspi-config nonint do_spi 0
   ```
2. **Configure Environment**:
   ```bash
   cp .env.example .env
   # Edit .env with your gateway credentials and Core RPi IP
   nano .env
   ```
3. **Install Core CA Certificate**:
   Copy the `ca.crt` generated on RPi 2 to `certs/core-ca.crt`:
   ```bash
   cp /path/to/ca.crt certs/core-ca.crt
   ```
4. **Deploy Containers**:
   ```bash
   docker compose up -d --build
   ```
5. **Verify Operation**:
   ```bash
   docker compose logs -f gateway
   ```
