# EnviroMesh — Security Testing & Proof-of-Concept Suite

This directory contains security testing guides, authorization boundaries, and Proof-of-Concept (PoC) validation reports for EnviroMesh.

> [!WARNING]
> All PoCs in this directory are restricted to authorized testing of EnviroMesh installations in isolated laboratory environments.
> Never target third-party infrastructure, public MQTT brokers, or production networks.
> Read and adhere strictly to [`rules-of-engagement.md`](rules-of-engagement.md) before conducting tests.
